Skills are organised into category folders under `skills/`:

- `skills/productivity/` — workflow and communication tools
- `skills/engineering/` — code and technical workflows

Every skill must have an entry in the category `README.md` with a one-line description linked to its `SKILL.md`, and an entry in the top-level `README.md`.

Each category folder has a `README.md` that lists every skill in that category with a one-line description, with the skill name linked to its `SKILL.md`.
